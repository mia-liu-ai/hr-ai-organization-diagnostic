# AI 组织诊断与行动共识平台

这是一个本地可运行的组织发展诊断 MVP，包含 React 前端、FastAPI 后端和 SQLite 持久化。产品目标是把项目创建、诊断设计、证据收集、AI 专家诊断会、数据洞察、报告和行动计划串成完整闭环。

主流程：

创建项目 → 设置诊断目标 → AI 预诊断会 → 编辑诊断假设 → 配置组织能力维度 → 生成胜任力模型 → 生成综合问卷 → 员工填写 → 数据洞察 → AI 专家诊断会 → 生成报告 → 制定行动计划 → 后续复盘

## 角色与演示账号

系统面向两类角色：

- 管理员：负责创建项目、配置诊断、生成问卷、查看洞察、运行 AI 专家诊断会、生成报告和行动计划。
- 员工：负责查看填写说明、完成问卷、参与 360 评审、提交开放反馈和查看必要记录。

推荐演示账号：

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `admin123` |
| 员工 | `employee` | `employee123` |

## 本地启动

安装依赖：

```bash
npm install
```

启动前端：

```bash
npm run dev
```

启动后端：

```bash
npm run dev:backend
```

构建检查：

```bash
npm run build
```

后端运行后可检查：

- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/api/health`

## 环境变量

复制 `.env.example` 为 `.env` 后按需配置。SQLite 默认会写入后端目录下的本地数据库文件，也可以使用：

```bash
DATABASE_URL=sqlite:///./hr360.sqlite3
```

模型配置通过统一 AI Provider 读取。不要把模型调用凭证写入代码或提交到仓库。

## 产品模块

- 首页：展示管理员使用向导或员工填写说明。
- 项目中心：创建、查看、编辑、删除、切换项目。
- 诊断设计：设置诊断目标、运行 AI 预诊断会、编辑并确认诊断假设、配置组织能力维度、生成胜任力模型。
- 证据收集：生成综合问卷，管理问卷中心、360 评审和员工反馈。
- 数据洞察：查看项目维度、问卷、反馈和诊断数据。
- AI 专家诊断会：基于真实证据进行多专家结构化分析，输出共识、分歧、置信度和行动建议。
- 报告与行动：生成诊断报告、行动计划和复盘追踪。
- 设置：配置模型和系统参数。

## 两个 AI 节点

AI 预诊断会位于设置诊断目标之后、编辑诊断假设之前。它根据项目背景和目标提出初步诊断假设、风险点和建议观察维度，是预诊断输入，不是最终结论。

AI 专家诊断会位于问卷、360、员工反馈和数据洞察之后。它基于真实证据进行专家辩论和诊断，输出关键组织问题、支持证据、反对证据、专家分歧、置信度和行动建议，用于报告和行动计划。

## 问卷生成逻辑

问卷不是独立功能，而是证据收集工具。系统会把已确认的诊断假设、组织能力维度和胜任力模型转化为可填写的问题，用来支持后续的数据洞察、AI 专家诊断会、诊断报告和行动计划。

- 组织诊断假设回答：“当前组织可能出了什么问题？”
- 组织能力维度回答：“我们从哪些组织能力角度观察问题？”
- 胜任力模型回答：“解决这些组织问题，需要管理者和员工具备哪些能力与行为？”
- 诊断问卷回答：“我们如何收集证据，验证这些假设和能力差距？”

## 数据隔离和持久化

所有项目相关数据必须绑定 `project_id`，包括组织能力维度、诊断假设、胜任力模型、人才画像、问卷、问卷问题、问卷回答、360 数据、员工反馈、AI 专家诊断会、报告和行动计划。

后端启动不会清空数据库。演示初始化只补齐缺失数据，不覆盖用户创建的项目和业务数据。

## 手动验收建议

1. 用管理员账号登录，确认首页显示新的主流程。
2. 创建项目 `111`，编辑项目名称、诊断场景、诊断目标、参与对象、项目状态和说明。
3. 创建项目 `222`，确认项目 `111` 仍存在。
4. 在项目 `111` 中新增、编辑、删除组织能力维度，并恢复默认八大维度。
5. 在项目 `111` 中新增并确认诊断假设。
6. 进入胜任力模型页面，确认能看到项目 `111` 已确认的诊断假设，并基于它生成模型。
7. 生成综合问卷，保存后到问卷中心查看问题来源和题型。
8. 切换到项目 `222`，确认看不到项目 `111` 的维度、假设、模型、问卷和诊断会结果。
9. 打开 AI 专家诊断会，确认专家角色、输入证据、诊断流程和结果结构都能展示。
10. 用员工账号登录，确认只能看到员工任务、填写说明、问卷、360 评审、员工反馈和完成记录。
